How the System Works

  1. The user enters electricity-related information.
  2. The website validates the entered values.
  3. The saved machine learning models receive the input.
  4. The models calculate predicted usage and bill estimates.
  5. The results page displays the predictions.
  6. The dashboard compares previous usage with predicted usage.

Input Features

Weather Information

Temperature, humidity and rainfall.

Appliance Usage

Fan usage and washing machine usage hours.

Previous Consumption

Previous month's electricity usage in kWh.

About the Technology

Python: Handles prediction logic.

FastAPI: Connects the website to the models.

Joblib: Loads the saved model files.

HTML and CSS: Display the user interface.

Chart.js: Displays usage comparison charts.

The predictions depend on the training data and the features expected by your saved models.
